# SteelShulkerEvent

Плагин **SteelShulkerEvent** для серверов Minecraft (Paper / Purpur / Spigot 1.16+).

## Описание
Оригинальный плагин ивентов и игровых механик сервера SteelRise.

## Установка
1. Скачайте актуальный `.jar` файл из раздела [Releases](../../releases).
2. Поместите `.jar` файл в директорию `plugins/` вашего сервера Minecraft.
3. Перезапустите сервер или загрузите плагин с помощью PlugManX.
